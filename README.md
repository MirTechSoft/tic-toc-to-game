# # ❌⭕ Tic-Toc-To Game  

A fun and interactive **Tic Tac Toe** web game built using **HTML5**, **CSS3**, **Bootstrap**, and **JavaScript**.  
Developed by **MirTechSoft**, this project brings the classic **X vs O** (Cross & Circle) game to life — complete with emojis, animations, and a clean, responsive layout.

---

## 🧠 About the Game  

**Tic-Toc-To Game** is an online version of the classic **Tic Tac Toe** board game where two players take turns marking spaces in a 3×3 grid.  
The player who succeeds in placing three of their marks in a horizontal, vertical, or diagonal row wins the game.  

At the end of each match:  
- 😄 **Winner gets a Happy Emoji** 🎉  
- 😢 **Loser gets a Sad Emoji** 💔  

This makes the game more engaging and fun to play for all ages!  

---

## 🚀 Features  

- 🎮 Classic Tic Tac Toe gameplay  
- 😄 Dynamic emoji reactions (Happy for winner, Sad for loser)  
- 🎨 Built with **HTML5, CSS3, Bootstrap, and JavaScript**  
- 💻 Fully responsive and browser-friendly  
- 🔄 Option to restart or play again instantly  
- ✨ Simple UI with smooth transitions  
- 🔧 Ready for future upgrades (AI mode, score tracking, etc.)
